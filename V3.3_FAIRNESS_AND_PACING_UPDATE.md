# V3.3 Fairness and pacing update

This release preserves the agreed Ludo rules while changing information visibility, turn pacing and presentation.

## Private capture-risk warnings

- Capture-risk calculations are never shown on the TV.
- A player can receive warnings only for their own token(s).
- The warning deliberately does not identify the threatening opponent or required die value.
- The host can turn **Private capture-risk warnings** ON or OFF at any point.
- The default is ON.

## Authoritative turn presentation

The server locks player interaction while a roll or move is still being presented. The effective flow is:

`AWAIT_ROLL → ROLLING → MOVING/RESOLVING → TURN_GAP → AWAIT_ROLL`

No phone can roll or select a token during the locked presentation phases. Extra turns from a usable six, capture or completed token also wait for the current presentation to finish before the Roll button becomes available again.

## Pacing

Standard mode is slightly slower than before. The four shared speed profiles remain Relaxed, Standard, Quick and Turbo. Dice, hops, capture resolution, HOME completion, foul presentation and the between-turn gap all derive from the same server-supplied timing profile.

## TV dice

The host dice is a single shared 3D cube. It tumbles and bounces before settling on the exact server-generated face. Phones show roll text but do not render a competing animated die.

## HOME-lane status

Each host player card now shows `HOME lane LOCKED` until that player makes the mandatory capture and `HOME lane UNLOCKED` afterwards. This is public historical game information, unlike calculated future capture risk.
